# Simple Calculator

A basic calculator made with Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division

- Basic unit conversions    
- Input validation    
- Handles division by zero    

## Requirements

- Python 3
## Usage

The program gives you a simple menu:

```text
1. Arithmetic operations
2. Unit conversion
3. Exit
```

For arithmetic operations, you can choose:

```text
1. Addition
2. Subtraction
3. Multiplication
4. Division
```

The unit converter currently supports:

```text
Kilometers ↔ Miles
Celsius ↔ Fahrenheit  
```
